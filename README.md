# ⚽ Dominators FC — Official Web Application

Welcome to the official web portal for **Dominators FC**. Built with responsive design, modern UI elements, interactive galleries, and optimized asset management, this repository hosts the official front-end for our club's news, squad lineups, founders, operational leadership, and tournament updates.

---

## 📌 Project Overview

* **Club Name:** Dominators FC
* **Motto:** *Dominating the pitch with passion, power, and precision.*
* **Tech Stack:** HTML5, CSS3 (CSS Variables & Flexbox/Grid), JavaScript (Vanilla ES6+), FontAwesome v6.

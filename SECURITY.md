# Security Policy

## Supported Versions

We actively update and support the main branch of the Dominators FC website.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

The safety and integrity of the **Dominators FC** web application are important to us. 

If you discover a security vulnerability, site error, or security issue regarding asset protection or external scripts:

1. **Do not** create a public GitHub issue.
2. Please contact the management or technical maintainer directly via our official social channels or email.
3. Include details of the vulnerability, steps to reproduce, and potential impact.

We aim to address and patch critical vulnerabilities as quickly as possible. Thank you for helping keep our platform safe!
